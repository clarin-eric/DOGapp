Digital Object Gateway

The goal of DOG is to breach the gap between entries in repositories and referenced resources. Manually registered repository configuration provides a mapping between collection's landing page URL or PID allowing easy retrieval of referenced resources.

Currently, DOG supports 3 primary functionalities:

  • sniff - checks if input PID points to a registered repository
  • fetch - fetches all PIDs of referenced resources in the metadata
  • is pid - checks if input string is a DOG parsable PID
